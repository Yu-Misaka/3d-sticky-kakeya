How this graph is computed

References in declaration types, proof bodies, private helpers and inductive data are followed. The expanded graph displays linked theorems and the root's immediate theorem inputs. Intermediate definitions and helpers are folded into edges; redundant edges are removed for readability. Every edge has a witness below. Lean and Mathlib are library boundaries.

These are references in the stored proof term, not a claim of minimal logical necessity. Type annotations, unused let bindings and arguments passed to a theorem still count. A reached theorem does not by itself establish equivalence to every informal formulation.

Which version of each paper result is used?

The middle column records the manuscript's manual proof mark. The last column is computed from Lean and treats each declaration version separately. A used type or proposition-valued definition is not counted as a proof. “Not used” refers only to this root's stored dependency closure.
